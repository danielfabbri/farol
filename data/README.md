# data/

Gerado automaticamente pelo GitHub Actions (`.github/workflows/intelligence.yml`). Não edite à mão.

- `latest.json`: edição atual, lida pelo app em `https://raw.githubusercontent.com/danielfabbri/farol/main/data/latest.json`
- `articles/AAAA-MM-DD.json`: artigos por dia (retenção de 120 dias)
- `editions/AAAA-MM-DD/HHMM.json`: edições por horário (21 dias)
- `trends/`: tendências
- `state/`: estado interno do pipeline (cache HTTP, itens vistos, uso da cota, execuções)

Contém apenas metadados públicos, links e resumos próprios — nunca o texto integral das publicações.
